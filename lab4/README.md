# Laboratory Work No. 4

This folder contains the xv6 programs and report for **The xv6 Shell from the Outside**.

## Laboratory files

- `sleep.c` - xv6 implementation of the `sleep` utility.
- `args.c` - xv6 argument-printing utility.
- `args_linux.c` - Linux comparison program.
- `Makefile` - xv6 build configuration used for the added programs.

## Report files

- `report/Lab4_Moisei_Daniel_FAF241_Report.tex` - editable Overleaf source matching the previous lab style.
- `report/Lab4_SO.pdf` - rendered PDF report.
- `report/figures/` - local screenshot assets referenced by the LaTeX source. Figure assets are excluded from Git by the repository `.gitignore`.
