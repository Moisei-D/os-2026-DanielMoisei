# Laboratory Work No. 5

This folder contains the executed experiments and completed report for **The File System with Your Own Hands**.

## Experiment files

- `run_experiments.sh` runs the required Linux commands as the current non-root user.
- `experiment-output.txt` contains the captured command output used in the report.
- `disk-summary-output.txt` contains the concise storage view used for its terminal evidence figure.
- `render_terminal_evidence.py` renders the captured output as terminal-style PNG evidence.

## Report files

- `report/Lab5_Moisei_Daniel_FAF241_Report.tex` is the editable LaTeX source matching the Lab 4 report structure.
- `report/Lab5_SO.pdf` is the compiled submission-ready PDF.
- `report/figures/` contains the evidence images referenced by the LaTeX source.
