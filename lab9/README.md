# Lab 9 - Watching System Calls with strace

- `syscalls.c` - open, write, read and close using only system calls.
- `run_lab9.sh` - runs all the commands of the lab and saves the output in `strace-output.txt` (needs `strace`: `paru -S strace`).
- `report.md` - the answers to the "Observe" boxes, with excerpts of the real output.
